
# 📊 Data Science Portfolio – Exploratory Data Analysis & Machine Learning Projects

Welcome to my Data Science Portfolio! This repository showcases a diverse collection of projects that demonstrate my skills in **data cleaning**, **exploratory data analysis (EDA)**, **machine learning**, and **data visualization**. Each project provides a comprehensive walk-through of the data science pipeline, from raw data to actionable insights.

---

## 📂 Repository Structure

| Project | Description | Technologies |
|---------|-------------|--------------|
| **🚗 Automobile Dataset EDA** | Analyzed car specs for pricing, fuel efficiency, and manufacturer trends. | Python, Pandas, Matplotlib, Seaborn |
| **🚢 Titanic Dataset EDA** | Survival analysis of Titanic passengers based on demographics and travel details. | Python, Pandas, Seaborn, Scikit-learn |
| **🏡 Ames Housing Price Prediction** | Built a linear regression model to predict house prices using key features. | Python, Pandas, Scikit-learn, Matplotlib |
| **📉 Telco Customer Churn Prediction** | Modeled churn behavior using Logistic Regression and Random Forest Classifier. | Python, Pandas, Scikit-learn, Seaborn |
| **🛒 Amazon Product Reviews – Sentiment Analysis** | Performed sentiment analysis using spaCy and TextBlob on Amazon reviews. | Python, spaCy, spacytextblob, Pandas, Seaborn |
| **📝 Slogan Classifier & Generator (LSTM Models)** | Built LSTM models to classify and generate business slogans. | Python, TensorFlow, spaCy |
| **📚 Shelf Track – Bookstore Management System** | CLI-based application for managing bookstore inventory with SQLite. | Python, SQLite3 |
| **📋 Task Manager – Terminal-Based Application** | Task assignment and tracking system with role-based access via text files. | Python |
| **🗺️ PCA & Clustering on USArrests Dataset** | Dimensionality reduction and clustering of US crime statistics using PCA. | Python, Scikit-learn, Seaborn, Matplotlib |

## 🚀 How to Run the Projects

1. **Clone the Repository**
    ```bash
    git clone https://github.com/CarliPeens/Data-Science.git
    cd Data-Science
    ```

2. **Navigate to a Specific Project Directory**
    ```bash
    cd project-folder-name
    ```

3. **Install Required Python Libraries**
    ```bash
    pip install -r requirements.txt  # If available
    ```
    Alternatively, manually install the libraries listed in the project's README.

4. **Run Jupyter Notebooks**
    ```bash
    jupyter notebook
    ```

5. **Follow Instructions Provided in Each Notebook or README.md**
